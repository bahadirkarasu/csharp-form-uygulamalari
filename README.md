# 🖥️ C# Windows Forms & Görsel Programlama – 14 Haftalık Proje ve Ödev Arşivi

Bu repository, üniversite **Görsel Programlama / C#** dersi kapsamında 14 hafta boyunca geliştirilen laboratuvar çalışmaları, "Sıra Sizde" ödevleri ve veritabanı destekli otomasyon projelerini içermektedir.

Temel form kontrollerinden başlayarak, algoritma kurma, koleksiyon/dizi yönetimi, hata yakalama mekanizmaları ve son haftada geliştirilen ilişkisel veritabanı destekli **Kütüphane Yönetim Otomasyonu**'na kadar kapsamlı bir gelişim sürecini modeller.

---

## 🛠️ Kullanılan Teknolojiler

- **Dil:** C# (.NET Framework)
- **Arayüz:** Windows Forms (WinForms)
- **Veritabanı:** SQL / MySQL (ADO.NET)
- **Geliştirme Ortamı:** Microsoft Visual Studio

## 🚀 Projeyi Çalıştırma

1. Bilgisayarınızda **Visual Studio** yüklü olduğundan emin olun (.NET masaüstü geliştirme paketiyle).
2. YeniProje.sln dosyasını Visual Studio ile açın.
3. Çalıştırmak istediğiniz haftanın formunu Program.cs içerisindeki Application.Run(new FormAdi()); satırına tanımlayın.
4. F5 tuşuna basarak projeyi derleyip çalıştırabilirsiniz.
